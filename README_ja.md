# 積分右左どっち？

[English](README.md)

公開URL：https://sogataro.github.io/integral-cards/

## 機能
- 左右の裏向きカードを選び、インテグラルを含め3〜7回のランダム回数で問題を作ります。四則演算は出せる場面で30％です。
- 隣接する因子は積。÷で分母モードが切り替わります。
- 不定積分・定積分、解答入力と別解の記号判定。
- 日英、全画面、使い方、設定、更新履歴。
- FBボタンから意見・不具合を送信。

## 使い方
カードを選んで次へ進み、計算開始。`*`、`^`、`sin(x)`、`log(x)`（`ln(x)`）、`exp(x)`、`abs(x)` を使って解答します。不定積分は `+C` または `+c` が必要。実数・ラジアン。スマホのピンチ拡大も可能です。

## ローカル起動
Node.js 18以降。インストール不要。
```
node server.cjs
node --test
```
PCは http://localhost:8018/ 、スマホは同じWi-FiからPCのLANアドレスで開きます。静的HTTPサーバーでも動作します。外部CDN・数学APIは使いません。

## 保存データ
レベル・言語と更新履歴の既読情報だけをlocalStorageの `integral-cards/` に保存。問題と解答は保存しません。FBの送信時だけ、本文・任意の連絡先・アプリ名・版・言語をGoogle Apps Scriptへ送ります。

## 計算の範囲と限界
MITのNerdamer 1.1.13を同梱（`vendor/package/license.txt`）。計算Workerは9秒で打ち切ります。解答を微分し、式の簡約・展開・対応する三角恒等式で再確認します。数値の不一致で誤答を検出しますが、数値一致だけで正解にはしません。AIによる推論サービスは使いません。

積分不可の確定は `sin(x)/x`、`cos(x)/x`、`exp(x)/x`、`1/log(x)` とその非零定数倍。他の未解決問題は判定保留。定積分は通常 [1,2] または [1,3]。三角関数を引くと [π/6,π/3] または [π/6,π/2] に切り替え、πのまま正確に計算します。因子に特異点があるときは相殺可能な場合も保守的に広義積分の判定を保留し、原始関数の差だけでは計算しません。近似小数の解答は否定できない場合に保留となるため、正確な式での入力を推奨します。
